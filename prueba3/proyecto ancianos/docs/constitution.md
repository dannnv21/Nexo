# Constitución del Proyecto: ¿Hablamos? (App Móvil)

1. **Simplicidad y Enfoque Móvil:** El stack tecnológico estará optimizado para una aplicación móvil ligera, fluida y fácil de mantener por el equipo.
2. **Trazabilidad Spec-Code:** Ninguna funcionalidad se programa sin estar previamente especificada mediante requisitos EARS en un `spec.md`.
3. **Separación Lógica e Interfaz Móvil:** La lógica de negocio y gestión de estados de llamada deben estar totalmente desacopladas de las vistas y componentes de la UI móvil.
4. **Política de Tests Obligatoria:** Todo requisito funcional móvil debe contar con pruebas asociadas que verifiquen su correcta ejecución.
5. **Persistencia y Conectividad Seguras:** Los datos de usuarios y la gestión de solicitudes de acompañamiento se manejarán de forma segura en entorno móvil.
6. **Idioma, Tono y Accesibilidad Móvil:** El código, los mensajes y la interfaz móvil estarán en español, con un diseño ultra-accesible (textos grandes, botones amplios) y un tono cálido ("Sin prisas. A tu ritmo").
